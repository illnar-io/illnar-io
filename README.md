### [PowerCV](https://github.com/illnar-io/PowerCV)
AI-driven backend system for CV parsing, structured data extraction, content generation, and job application workflow automation.

- FastAPI async architecture with typed request validation

- Celery + Redis for asynchronous AI task processing
- PostgreSQL with optimized queries (150–220ms avg response time)

### [Power Hz](https://github.com/illnar-io/power_hz)
Intelligent Linux power management system that dynamically optimizes display refresh rates, GPU performance, and power consumption based on battery status.

- Dynamic refresh rate switching (24Hz–240Hz+) with VRR/FreeSync/G-Sync support
- Real-time battery monitoring with automatic mode switching
- 30–50% battery life improvement in ultra power saving mode
- Systemd service integration with continuous metrics logging

### [Power Switcher](https://github.com/illnar-io/power_switcher)
DE-independent keyboard layout auto-switcher for Linux Wayland.

- Kernel-level keyboard grabbing via `evdev`, virtual `uinput` passthrough
- N-gram language detection with auto-convert on word boundary
- Works on GNOME, KDE Plasma, Sway, Hyprland
- Multi-layout support (EN, RU, UA, DE)

### [DUSK Kernel](https://github.com/illnar-io/dusk_kernel)
Custom Android GKI kernel for Pixel 6 (oriole) with integrated root, stealth, and compatibility layers.

- KernelSU-Next for kernel-mode root access
- SUSFS inline hooks for root hiding and userspace masking
- ntSync backport for Wine/Proton gaming performance
- Droidspaces container isolation for Android app sandboxing
- GitHub Actions CI/CD with automated kernel builds
